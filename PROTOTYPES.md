Prototype 2 uses an editorial navigation rail, magazine article rows, an annotated reading layout, and an activity catalog. Prototype 3 uses horizontal navigation, a guided journey, visual article tiles, a single-column article, and an activity path. Both serve students and educators equally.

Each download directory contains a standalone homepage PNG and JPG; all five requested page types in Images/; a Clickable Website/ folder with index.html; and ZIP downloads in each format. The Complete Download ZIP includes the five PNGs, five JPGs and clickable HTML.

Open downloaded HTML with its assets kept together. Live surveys require the hosted website and site access.
